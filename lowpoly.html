Low-poly structures, sized for the village.

Flat-shaded stand-ins for the farm, the two homes and the woodcutter hut. They keep the game’s 2:1 grid and footprints while the real structures are being modelled in Blender, so scale, placement and economy can be tested now.

4 structures 2:1 dimetric no outlines v0.1
The set

Four pieces, one language

Every piece is generated from the same kit: same projection, same three-value materials, same footprint as the slot it occupies in the game.

Style contract

Rules that keep it coherent

  1. Flat faces onlyNo gradients or soft airbrush shading. One plane, one value; the facets carry the form.
  2. One sun, three valuesLight comes from the lower-left. Each material gets a lit, base and shade tone — and nothing else.
  3. No outlinesSilhouette and value contrast do the work. Dark timber is real structure, not a stroke around the building.
  4. Grid firstHome 3 × 3, farm 5 × 2, hut 2 × 2. Art sits on the existing cells, so Blender models can replace it without a layout pass.
Palette

Warm build, cool ground

Thatch and timber carry the buildings; moss greens stay in the ground so structures read first. The gold accent matches the market and wheat HUD.

Drop-in

Same cell, same anchor

The kit returns plain SVG or a data URI. Swap it for the current sprite without touching footprints, hit areas or placement rules.

// js/lowpoly-kit.js
const svg = LOWPOLY.art('cabin');   // markup
const url = LOWPOLY.data('cabin');  // data:image/svg+xml

// sizes stay true to the grid
// cabin / manor 3×3 · farm 5×2 · hut 2×2
